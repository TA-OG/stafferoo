# Stafferoo Brand Fonts

## Required Font File

Place the Edensor font file here:
- **File name:** `Edensor-FREE.otf`
- **Full path:** `app/fonts/Edensor-FREE.otf`
- **Source:** Provided brand asset

This font is used for:
- Headings (h1, h2)
- Page titles
- Logo wordmark areas
- Brand display text

Body text uses a system sans-serif stack for optimal readability.
